Icon của từng game, đúng các tên file sau (ảnh vuông, khuyến nghị >= 512x512):

  cube-land.jpg      -> Cube Land        (khẩu pháo bắn khối lập phương)
  sweepy-snake.jpg   -> Sweepy Snake     (con rắn xanh lá trên khay tím)
  cube-crumble.jpg   -> Cube Crumble     (khối lục giác vỡ ra bi tím)
  city-connect.jpg   -> City Connect     (nhà + đường + xe hơi)

Nếu file chưa tồn tại, trang web sẽ tự động fallback về icon Lucide mặc định
của card đó — không bị vỡ layout. Đổi đuôi file (vd sang .png) thì nhớ sửa
luôn thuộc tính src trong index.html.
